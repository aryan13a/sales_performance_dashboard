# 🛒 Superstore Sales Performance Dashboard

## 📌 Project Overview
Analyzed 10,000+ sales transactions from a retail superstore 
to identify revenue trends, top customers, and regional performance.

## 🛠️ Tools Used
- Python (pandas, matplotlib, seaborn)
- Tableau Public
- Kaggle Notebooks

## 📊 Key Insights
- Total Revenue: $2,297,201 with 12.47% profit margin
- Technology is the highest revenue category
- Sean Miller is the top customer by sales
- West region leads in both sales and profit

## 📁 Project Structure
- `sales_analysis.ipynb` — Data cleaning & KPI analysis
- `superstore_cleaned.csv` — Cleaned dataset
- `monthly_trend.png` — Monthly sales chart
- `category_sales.png` — Sales by category chart
- `top_customer.png` — Top 10 customers chart
